# Roblox-Tag-Based-Collision-Components
Without using metatables, a Tag/component based handler that handles primarily .touched events (and object data) using a priority based system.

![mentos](/Mentos.gif)

Note: This project requires alot of overhead and boilerplate split between multiple files in different places of a roblox place. A more elegant solution is possible using metatables or an [OOP solution](https://github.com/shalanfeh/Lua/blob/main/EmptyTemplate.lua).
