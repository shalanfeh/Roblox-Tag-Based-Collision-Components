# Roblox-Tag-Based-Collision-Components
Without using metatables, a Tag/component based system that handles .touched events with respect to prioritization.
![mentos](/Mentos.gif)

Note: This project requires alot of overhead and boilerplate split between multiple files in different places of a roblox place. A more elegant solution is possible using metatables or an [OOP solution-like](https://github.com/shalanfeh/Lua/blob/main/EmptyTemplate.lua).
